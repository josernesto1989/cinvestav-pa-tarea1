Tarea 1 del Master Programación Avanzada

## Intrucciones de compilación

### Usa el comando para generar el ejecutable en la carpeta build(previamente creada)
```
gcc -O3 -mbmi2 -madx main.c -o ./build/main.o
```

### O usando el script build_and_run
```
./build_and_run.sh
```
